# Authoring Context

Background for the [spec](../spec/README.md): who this is for, where it runs, and why it is shaped the way it is. Readers have the spec and want the reasons.

## Scope

- What the spec cannot say: motivation, rejected alternatives, facts about the outside world, and how sure we are.
- Nothing here is a rule. Where a page and the spec disagree, the spec wins and the page is fixed.
- A decision is stated in the spec and explained here, never the reverse.

## Shape

- Same shape as the spec: one page per topic, a headline, then sections of bullets.
- Facts about browsers, libraries, and papers go stale. Say when a fact was checked and where it came from.
- Say what was verified and what was only read about. A future reader cannot tell otherwise.
- Describe kinds of application by their properties. A named example becomes a design target for whoever reads it next.
